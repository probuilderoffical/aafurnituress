# Rivaq Studio website

Static, multi-page marketing website for Rivaq Studio (the current verified name of the Facebook page at `facebook.com/AAfurnituress`).

## Structure

- `index.html` — homepage
- `about.html` — studio and services
- `collections.html` — verified furniture directions
- `projects.html` — official portfolio gallery
- `contact.html` — WhatsApp enquiry flow
- `assets/css/style.css` — design system and responsive layouts
- `assets/js/site.js` — navigation, FAQ, gallery and enquiry interactions
- `assets/images/` — optimized local copies of official public imagery

Serve the repository root with any static HTTP server.
